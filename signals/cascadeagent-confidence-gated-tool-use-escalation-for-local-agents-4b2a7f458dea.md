## What looked useful

The mechanism is cost-sensitive. At tool cost 0.05 and 0.12, always-tool is usually the best utility baseline; at cost 0.20, confidence gating beats the best baseline in 3/5 scenarios; at cost 0.30, it beats the best baseline in 5/5 scenarios while preserving a large success gain over never-tool.

## Boundaries and scale limits

Synthetic single-step tasks only; confidence is generated by a controllable simulator rather than a real local LLM; tools are modeled as fixed-accuracy calls with scalar cost; no multi-step agent traces, real filesystem/browser/shell tools, latency, privacy risk, or human grading.

## Claim scope

In a reproducible synthetic local-agent control benchmark, confidence-gated tool escalation reduces tool calls by about 47.7 percentage points versus always-tool execution and becomes utility-positive versus the best simple baseline when per-tool cost is sufficiently high.

## Why it stopped

Closed as no-paper useful signal: bounded synthetic evidence supports a conditional mechanism, but direct local-agent evidence is required for practical validation.

## Recommended next action

Run a bounded real-agent follow-up using local model confidence or verifier scores on a graded task suite with observable tool calls before making any paper claim.
