## What looked useful

Across 20 seeds and 3,600 task attempts, learned doctrine memory improved held-out test success from 0.0 for no-memory to 1.0, matching oracle memory across all five task families after learning one rule per family during training.

## Boundaries and scale limits

Synthetic deterministic tasks only; no real LLM/LangGraph action generation, no noisy natural-language rule extraction, no adversarial transfer, and no long-horizon software-development workload.

## Claim scope

In a deterministic local file/shell tool-use harness with five repeated doctrine-sensitive task families, automatic verifier-derived doctrine memory prevents repeated violations after first failure and reaches oracle-memory held-out test performance.

## Why it stopped

No-paper closure: local mechanism is supported, but evidence is synthetic and deterministic rather than direct real-agent validation.

## Recommended next action

Run a bounded deepen follow-up inside an actual LangGraph/tool-calling agent loop with noisy verifier text and unseen surface-form transfer tasks.
