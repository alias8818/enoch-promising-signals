## What looked useful

Across 1,280 primary mined-noise cases, transcript_search reached 0.4852 accuracy while conflict-aware layered memory reached 1.0000; 659 baseline-failure/layered-success counterexamples were mined. The no-noise control improved transcript_search to 0.6703 and the shuffled blind-label control drove layered accuracy to 0.0000, supporting noise causality and no label leakage in this synthetic setup.

## Boundaries and scale limits

Noise was generated by templates rather than a live LLM; replay tasks were synthetic; no real operator corpus, API LLM generation, or large-scale model-in-the-loop validation was used.

## Claim scope

Deterministic synthetic replay benchmark with blind labels, fixed seeds, targeted noisy replay distractors, transcript-search baseline, flat-retrieval ablation, shuffled-label control, and conflict-aware layered memory comparison.
