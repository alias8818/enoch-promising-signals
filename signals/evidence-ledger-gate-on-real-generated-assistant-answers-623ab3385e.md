## What looked useful

Evidence-ledger gating is useful when applied post-hoc to real generated answers with deterministic exact-quote verification, but relying on the model to self-produce exact ledgers caused severe utility loss or total abstention. Support-only verification is insufficient for correctness.

## Boundaries and scale limits

Single small instruction model, SQuAD extractive QA, greedy decoding, and heuristic exact-quote verifier. The verifier checks answer-context support but not full question-answer relevance, and it passed 142/1000 context-supported but question-wrong post-hoc answers.

## Claim scope

On 1,000 fixed-seed SQuAD validation examples generated by google/flan-t5-small, a post-hoc exact-quote evidence-ledger gate reduced measured unsupported sentence rate from 1.000 to 0.000 while reducing gold-containing answer rate from 0.826 to 0.785; prompt-only self-ledger generation was not viable for this model.

## Why it stopped

No-paper useful signal: the post-hoc gate mechanism worked on direct generated answers, but prompt self-ledger gating failed and the verifier admitted context-supported wrong answers, so the evidence is not publication-grade.

## Recommended next action

Run one bounded deepen test using a stronger instruction model and a verifier that jointly checks exact evidence support and question-answer relevance; stop if accuracy drops more than 5 percentage points versus plain or wrong supported passes exceed 5%.
