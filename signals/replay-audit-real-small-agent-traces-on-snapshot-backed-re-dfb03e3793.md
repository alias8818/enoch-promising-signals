## What looked useful

Snapshot-backed replay was useful for reproducible repeated audit, but robust audit requires both step-level precondition checks and final-state hashing. Final hash equality alone missed stale persistent replays because the workspace was already in the expected terminal state.

## Boundaries and scale limits

The traces were generated by a deterministic local harness rather than imported from independent real LLM-agent runs. The test covers tiny file-edit tasks only, with no network tools, flaky external state, long-horizon planning, multi-repository work, or large trace corpus.

## Claim scope

In a local scripted four-task small-agent trace proxy, per-run snapshot restore produced deterministic replay with 160/160 passing checks and 0 audit errors; no-restore repeated replay produced stale-trace audit errors on 117/160 runs, and drift controls showed final-state hash mismatches even when functional checks passed.

## Why it stopped

Closed as no-paper useful signal because the evidence is a scripted local proxy rather than direct real-trace validation.

## Recommended next action

Run a bounded deepen follow-up on an imported corpus of real small-agent traces with captured base snapshots, comparing snapshot replay, persistent replay, and drift controls using the same step-level and final-state audit metrics.
