## What looked useful

Across 60 scenarios, the operator codec reconstructed exactly, won 48/48 structured or mixed scenarios, and lost 12/12 fully random controls. Median operator/best-baseline size ratios were 1.0049 at 0% structured transitions, 0.8246 at 25%, 0.6121 at 50%, 0.3643 at 75%, and 0.0118 at 100%.

## Boundaries and scale limits

Synthetic traces only; dimensions 64 and 256; lengths 1024 and 4096; fixed hand-coded operators; CPU-only local benchmark; no real LLM memory, KV-cache, conversation trace, learned operator discovery, latency, or downstream quality evidence.

## Claim scope

A fixed-library operator stream can losslessly compress synthetic integer-vector memory traces better than raw/delta zlib/lzma baselines when transitions are generated by reusable operators; it is not a universal compressor and loses slightly on fully random traces.

## Why it stopped

Closed as no-paper useful signal because current evidence is synthetic and fixed-library only; it supports a conditional mechanism but not a direct publication-grade claim about real operator-model memory compression.

## Recommended next action

Run a bounded real-trace follow-up using actual agent or model memory logs and compare fixed-library plus learned-operator encoding against raw/delta compressed baselines with exact reconstruction and task-level utility checks.
