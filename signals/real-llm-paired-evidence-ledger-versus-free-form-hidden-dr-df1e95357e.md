## What looked useful

In the proxy benchmark, evidence-ledger mode achieved 1.000 accuracy and 0.000 trap hidden-drift rate; free-form mode achieved 0.667 accuracy and 0.667 trap hidden-drift rate. This supports the audit mechanism but not the real-LLM benchmark claim.

## Boundaries and scale limits

No real LLM runtime was available on this host: ollama was absent and transformers, torch, llama_cpp, and openai Python modules were unavailable. No model prompting, sampling, tool use, or multi-seed LLM variability was tested.

## Claim scope

Deterministic 12-task paired proxy benchmark only. Evidence-ledger claims were mechanically verified against explicit evidence references; free-form hidden drift was simulated, not generated by a real LLM.

## Why it stopped

Proxy-only early result: the host lacked a usable real-LLM runtime, so the requested real-LLM claim remains unvalidated.

## Recommended next action

Run the same paired task harness with a real local or API LLM backend, randomized task order, multiple seeds or temperatures, and blind scoring.
