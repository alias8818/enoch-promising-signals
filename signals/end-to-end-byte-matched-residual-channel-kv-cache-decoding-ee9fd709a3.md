## What looked useful

Generated byte token streams matched full-KV decoding for all 5 Tier 1 runs with zero mismatch positions. Logits were not bitwise equal; maximum absolute fp32 logit drift was 5.960464477539062e-07, below the observed minimum full-baseline argmax margin of 0.00042831897735595703.

## Boundaries and scale limits

The test used random toy weights, greedy decoding, short prompts, 32 decode steps, and a Python/PyTorch harness. It did not test pretrained language models, real text corpora, fused production kernels, balanced warmed-up throughput, long contexts, sampling, quantized caches, or bitwise-logit equality.

## Claim scope

In a deterministic 4-layer, 128-wide toy causal transformer with a 256-token byte vocabulary, residual-source caching that stores the per-layer normalized K/V source vector reproduced full-KV greedy generated byte tokens across 5 seeds while using 0.5x the cache tensor bytes.

## Why it stopped

No-paper useful signal: the Tier 1 direct toy test supports greedy byte-token equality for the mechanism, but it is not full validation and does not establish bitwise logits, pretrained-model behavior, or production serving performance.

## Recommended next action

Run a bounded deepen test in a GPT-2-small-class pretrained model over a fixed real text/byte prompt suite, measuring byte equality, logit drift, argmax margins, memory, and balanced warmed-up throughput.
