## What looked useful

Across 2,000 tasks per condition, the evidence ledger reduced unsupported claims per requested fact from 0.6746 for exact_no_ledger to 0.0000 with clean reliability metadata, 0.0942 with 10% misleading metadata, and 0.2424 with 25% misleading metadata; at 50% misleading metadata it degraded to 0.4981, identifying metadata quality as the main failure boundary.

## Boundaries and scale limits

No LLM agent was evaluated; documents were synthetic and regular; source reliability metadata was generated by the benchmark; real retrieval, extraction noise, adversarial formatting, and human report quality remain untested.

## Claim scope

In a deterministic synthetic factual-QA benchmark with near-entity distractors, stale conflicts, and controlled reliability metadata, a structured evidence ledger reduced unsupported claims versus raw-context and exact-entity non-ledger baselines.

## Why it stopped

Useful proxy evidence was produced, but it is synthetic and deterministic rather than direct evidence from LLM agents on real research corpora, so this should remain a no-paper result.

## Recommended next action

Run a bounded real-agent follow-up using the same ledger interface inside an LLM retrieval loop on a small labeled corpus, with matched prompting and retrieval baselines.
