## What looked useful

Verified external anchors achieved mean true fact recall 0.981 versus 0.146 for suffix-only, mean accuracy 0.991 versus 0.573, and 1.0 corrupted-anchor detection across seeds 0, 1, and 2. The no-hash ablation recovered slightly more facts but rejected 0% of corrupted anchors, showing the auditability value of hash/evidence verification.

## Boundaries and scale limits

The test used local trace logs, deterministic schema-derived facts, seeded false mutations, and a simulated suffix truncation. It did not evaluate human-authored or model-authored memory entries, live agent resumption, downstream task success, production storage, privacy, or adaptive adversaries.

## Claim scope

Across 3 fixed-seed deterministic runs over 40 real local Codex/Enoch agent traces per run, externally persisted verified anchors recovered trace facts after suffix-only hard cutover much better than a suffix-only baseline and close to a full-trace oracle, while rejecting seeded corrupted anchors.

## Why it stopped

Useful Tier 2 mechanism evidence, but no paper decision because memory entries were generated by the harness and downstream agent behavior was not measured.

## Recommended next action

Run a bounded deepen test using held-out real traces with human-authored or model-authored anchor memories and a resume-time agent/verifier task; stop if verified anchors do not beat suffix-only by at least 0.25 true-recall while keeping invalid-anchor acceptance below 5%.
